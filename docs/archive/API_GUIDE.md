# 법제처 OpenAPI 활용 가이드 (프로젝트 정리본)

> 군포시 조례 정법성 보조 시스템에서 사용하는 법제처 국가법령정보 OpenAPI 정리.
> 공식 가이드: https://open.law.go.kr/LSO/openApi/guideList.do
> ✅ = 이 프로젝트에서 실호출로 검증됨 (OC 키 사용, 2026-06-24)

## 공통

- 엔드포인트
  - 목록 검색: `http://www.law.go.kr/DRF/lawSearch.do`
  - 본문 조회: `http://www.law.go.kr/DRF/lawService.do`
- 필수 파라미터: `OC`(인증값=신청 이메일 ID), `target`(서비스 대상), `type`(HTML/XML/JSON)
- 인증: open.law.go.kr 에서 무료 발급. **소스에 저장하지 않음** — 환경변수 `LAW_OC_KEY` 또는 기동 시 입력.

## 1. 자치법규 (target=ordin)

### 1-1. 목록 조회 — `lawSearch.do?target=ordin` ✅
| 파라미터 | 필수 | 설명 |
|---|---|---|
| target | ✓ | `ordin` (또는 `ordinfd` 분야/분류) |
| query | | 검색어 (default `*`) |
| search | | 검색범위: `1`=자치법규명(기본), **`2`=본문 전문검색** |
| org / sborg | | 광역(org) + 시군구(sborg) 지자체코드. 군포=org `6410000`(경기)·sborg `4020000` |
| knd | | 종류: `30001`조례 `30002`규칙 `30003`훈령 `30004`예규 `30006`기타 `30010`고시 `30011`의회규칙 |
| rrClsCd | | 제개정 종류: `300201`제정 `300202`일부개정 `300203`전부개정 `300204`폐지 `300205`폐지제정 **`300206`일괄개정** `300207`일괄폐지 `300208`타법개정 `300209`타법폐지 `300214`기타 |
| nw | | `1`현행(기본) `2`연혁 |
| efYd | | 시행일자 범위 `20090101~20090130` |
| ancYd / ancNo | | 공포일자 / 공포번호 범위 |
| date / nb | | 공포일자 / 공포번호 단건 |
| ordinFd | | 분류코드별 (지자체 분야코드 `target=ordinfd`로 조회) |
| lsChapNo | | 법령분야별 (`01000000`=제1편 등) |
| gana | | 사전식 (`ga`,`na`…) |
| display / page | | 개수(기본20·최대100) / 페이지 |
| sort | | `efasc`/`efdes`(시행일) 등 |

응답: 자치법규일련번호(MST), 자치법규명, 자치법규ID, 공포일자/번호, 제개정구분명, 지자체기관명, 자치법규종류, 시행일자, 자치법규상세링크, 자치법규분야명, 참조데이터구분

> **`search=2`(본문 전문검색)** → 특정 문구(예: 옛 명칭 "안전행정부") 포함 조례 일괄 색출에 활용 → 점검 #3.
> **`rrClsCd`** → 폐지(`300204`) 등 제외하거나 특정 개정유형만 추리는 데 활용.
> 분야/분류 목록은 `lawSearch.do?target=ordinfd&org=...` (응답: 기관코드·분류seq·분류명·해당자치법규갯수).

### 1-2. 본문 조회 — `lawService.do?target=ordin` ✅
파라미터: `ID`(자치법규ID) 또는 `MST`(일련번호), `type`
응답:
- 기본정보: 자치법규ID/일련번호/명, 공포일자·번호, **시행일자**, 자치법규종류(`C0001`조례 `C0002`규칙 `C0003`훈령 `C0004`예규 `C0006`기타 `C0010`고시 `C0011`의회규칙), 지자체기관명, **자치법규발의종류**, 담당부서명/전화번호, 제개정정보
- **조문**: 조문번호, **조문여부**(`Y`=조 / `N`=편·장·절·관), 조제목, 조내용 ← 인용추출 원천
- **부칙**: 부칙공포일자·번호·내용
- 제개정: 개정문내용, 제개정이유내용
- 별표: 별표번호/가지번호/구분/제목/첨부파일명/내용
  > ⚠️ **자치법규 별표 내용은 서울시교육청·본청만 제공** → **군포는 별표 본문 안 옴.** 별표 안의 인용은 못 봄(영향 제한적, 인용은 대개 조문 내).

> 비교 **기준일자 = 조례 `시행일자`**(현행=최종 개정 시행일). 인용추출은 `조문여부=Y`인 조내용 + 개정문/제개정이유 대상.

## 2. 자치법규 ↔ 법령 연계 (lnk* 계열)

> ⚠️ **세 API 모두 "법령 단위"까지만 제공 — 조문(제○조) 단위 연계는 없음.**
> 조문 인용은 조례 본문 인용추출로 별도 확보해야 함.
> ✅ `lnkOrg`는 OC 키로 접근 확인됨 (인계 노트의 "위임 API 권한없음"과 별개 — lnk 계열은 열려 있음).

### 2-1. 연계 조례 목록 — `lawSearch.do?target=lnkOrd`
입력: `query`(법규명), display/page/sort, popYn
응답: 자치법규 정보만 (법령 정보 없음)

### 2-2. 연계 법령별 조례 목록 — `lawSearch.do?target=lnkLsOrd`
입력: **`knd` = 법령ID** (이름은 knd지만 값은 법령ID. 샘플 `knd=002118`='건축법 시행령')
응답: 해당 법령에 연계된 자치법규 목록
> ⭐ **향후 계획(법령 개정→영향 조례)에 정확히 맞는 역방향 API.** 법령ID로 영향 조례를 역조회.

### 2-3. 연계 조례 지자체별 목록 — `lawSearch.do?target=lnkOrg` ✅ ⭐
입력: **`org` = 지자체 기관코드**, display/page/sort, popYn
응답: 자치법규일련번호/명/ID, 공포·시행일자, 제개정구분명, 자치법규종류, **`법령명한글` + `법령ID`**
> **이 프로젝트의 핵심 수집원.** 군포(org=`4020000`) 실호출 시 **433건** (경기 6410000=670건).
> 조례별 연계 상위법령의 **법령ID를 직접** 줌 → 이름→ID 검색(오매칭) 단계 제거.

## 3. 법령 본문/연혁 (상위법령 점검용)

### 3-1. 현행 법령 본문 — `lawService.do?target=law&ID=법령ID` ✅
조문 단위(`조문단위`)에 **`조문시행일자`, `조문이동이전`, `조문이동이후`, `조문변경여부`** 포함.
> ✅ 검증: 「지적재조사에 관한 특별법」(법령ID `011463`) 45개 조문 파싱, 제30~32조 `조문시행일자=20260102` 확인.
> → **`조문시행일자` > 조례 제정일** 이면 "그 후 개정됨"(② 내용변경 의심)을 **과거 데이터 없이** 판정 가능.
> ⚠️ `조문이동이전/이후` 형식이 `'000000'`(코드형)으로 옴 — 실제 이동 있는 법령으로 형식 재확인 필요(기존 phase6의 `'제30조'` 문자열 비교 로직과 불일치 가능).

### 3-2. 기타 (인계 노트 기준, 일부 미검증)
- `target=eflaw` (시행일자별 목록/본문) — 과거 시점 본문. `efYd`는 검색엔 작동, **본문 조회엔 무력**(인계 노트).
- `target=oldAndNew` (신구법 비교) — 최근 개정의 구/신 조문.
- 과거 시점 조문 내용이 필요하면(2단계 수정안 생성): **법령 연혁 목록 → 조례 제정일 이전 시행본 → 그 버전 본문** 경로 검토.

## 설계 시사점 요약

1. **법령 식별 = `lnkOrg`** (법령ID 직접·공식) → 정규식 추출의 누락 교차검증.
2. **조문 식별 = 조례 본문 인용추출** (lnk가 조문을 안 주므로 여전히 필요).
3. **변경 판정 = 현행 법령 본문**(`조문시행일자`/`조문이동`) — 1단계는 과거 데이터 불필요.
4. **수집은 경계 있는 코퍼스**(군포 조례 + 그들이 인용한 법령만) → 로컬 DB, 비교는 오프라인.
5. **역방향(향후)**: `lnkLsOrd`로 법령ID→영향 조례.

### 검토 결론 — "이 키들로 거의 다 해결되나?"
1단계에 필요한 API는 **4종으로 확정**:
- `ordin` 목록 → 군포 전수 수집 (필터: org/sborg/knd/rrClsCd)
- `ordin` 본문 → 조문·시행일자 (인용추출 원천 + 비교 기준일)
- `lnkOrg` → 조례별 연계 **법령ID**(공식)
- `law` 본문 → 상위법령 조문시행일자·조문이동 (변경 판정)

✅ **조례 쪽 입력 데이터는 `ordin` 목록+본문으로 충분.**
남는 한 조각:
- ⚠️ **비교 대상(상위법령 조문)은 `target=law`가 별도 필요** — 자치법규 API엔 없음.
- ⚠️ **"제 몇 조"는 결국 본문 인용추출에 의존** (lnk·연계도 조문 단위 미제공) → **인용추출 정확도가 1단계 품질의 관건.**
- ⚠️ 군포 별표 본문 미제공.

## 권한 확인 메모 (OC 키 기준)
- ✅ 접근됨: `ordin` 목록/본문, `law` 본문, `lnkOrg`
- ❌ 권한없음(인계 노트): `lsHstInf`, `lsHst`, `lsJoHst`, `joHst`, `delegated`, `lsAbbrv` 등
