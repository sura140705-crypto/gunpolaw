# 군포시 조례정비 시스템

군포시 조례·규칙 등 자치법규의 정비 작업을 지원하는 시스템.

## 개요

- (작성 예정) 프로젝트의 목적과 배경
- (작성 예정) 주요 기능

## 개발 환경

- Python 3.14
- 가상환경: `.venv`

## 시작하기

```powershell
# 가상환경 생성 및 활성화
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 의존성 설치
pip install -r requirements.txt
```
