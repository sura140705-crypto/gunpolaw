========================================
 DB 갱신 + 배포 - 사용법 (도움 없이 혼자 하기)
========================================

■ 처음 한 번만 준비
  1) 이 폴더의 oc_key.txt 를 메모장으로 엽니다.
  2) "여기에_OC_키를_붙여넣으세요" 를 지우고, 발급받은 OC 키를
     한 줄로 붙여넣고 저장합니다.
     (이 파일은 git에 안 올라갑니다 - .gitignore 처리됨)

■ 매번 갱신할 때 (2주에 한 번 등)
  - DB갱신_배포.bat 파일을 더블클릭.
  - 창이 뜨고 [1/5]~[5/5] 순서로 자동 진행됩니다.
    1/5 OC 키 로드
    2/5 증분 수집·분석 (신규/변경만 API로 받음 - 수 분 소요)
    3/5 정적 사이트 재생성
    4/5 코드 리포 변경분 커밋 (보통 없음)
    5/5 공개 사이트 배포(git push) -> GitHub Pages 갱신
  - "갱신 완료!" 가 뜨면 성공. 창은 닫아도 됩니다.
  - 공개 주소: https://sura140705-crypto.github.io/gunpolaw-view/

■ 참고
  - gunpolaw.db(600MB+)는 용량 때문에 GitHub에 올리지 않습니다.
    DB는 이 PC 로컬에만 있고, 사람들이 보는 건 공개 사이트입니다.
  - 실패하면 창에 [오류] 메시지가 남습니다. 그 내용과
    batch_incr.log 를 확인하세요. (git push 실패는 대개 로그인/네트워크)
  - git push 시 GitHub 로그인이 필요할 수 있습니다(최초 1회).

■ 문제가 안 풀리면
  - 창에 뜬 [오류] 줄과 batch_incr.log 내용을 그대로 캡처해서 문의.
